# Hi, I'm Dominic

Data scientist and indie developer in Vancouver. Master of Data Science (UBC), BSc in Mathematics with a minor in actuarial science (HKUST).

## Things I've built

- **[D2D (Dialogue2Data)](https://github.com/avalanche-strategy/D2D)**: my UBC capstone with Fathom. An open-source Python package that turns interview transcripts into structured data using retrieval and LLMs, plus an LLM evaluator. It raised answer correctness from 2.2 to 4.13 out of 5 over the client's plain-LLM baseline. I wrote most of the processing pipeline and the async calls that cut 100 transcripts from about an hour to under 10 minutes.
- **[TidyWL](https://tidywl.com)**: a browser extension to search, bulk delete and sort your YouTube Watch Later. About 5,000 installs. [Chrome Web Store](https://chromewebstore.google.com/detail/watch-later-tidy/fkelmapobieliokjcmnilmjllacmbfjo)
- **[Omodo](https://www.omodo.ai)**: an AI app for the goal you keep putting off. Tell it when you're free and it plans short sessions for those times, then reminds you before each one.
- **[Steward](https://github.com/dominic-lam/steward)**: a macOS menu bar app for claude.ai with a usage meter and a conversation manager.
- **[magicbar](https://github.com/dominic-lam/magicbar)**: a macOS menu bar battery warner for Apple's Magic keyboard, mouse and trackpad.
- **[ext-reload](https://github.com/dominic-lam/ext-reload)**: reloads an unpacked Chrome extension from the command line, so your coding agent never has to ask you to press Reload.
- **[vancrime](https://github.com/dominic-lam/vancrime)**: an auto-refreshing Vancouver crime map. Static Leaflet plus a GitHub Actions cron, no server.
